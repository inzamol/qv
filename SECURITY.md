# Security Policy

## Supported Versions

Security updates and patches are actively maintained for the following versions of `qv`:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

The `qv` maintainers take the security of our platform and user projects seriously.

If you discover a security vulnerability in `qv`, please **do not open a public GitHub issue**. Instead, follow responsible disclosure:

1. **GitHub Private Vulnerability Reporting**: Submit an advisory privately via [GitHub Security Advisories](https://github.com/inzamol/qv/security/advisories/new).
2. **Direct Contact**: If unable to use GitHub Security Advisories, contact the project maintainer directly at `inzamul.hoque@gmail.com` with the subject line `[SECURITY] qv Vulnerability Report`.

### What to Include
Please provide as much information as possible to help us reproduce and remediate the issue quickly:
- Description of the vulnerability and its potential impact.
- Minimal reproducible example, project configuration, or proof of concept.
- Affected versions of `qv`, Python interpreter, and OS environment.

### Our Commitment
- We will acknowledge receipt of your report within **48 hours**.
- We will provide regular progress updates as we investigate and develop a patch.
- We will credit you in the release notes and advisory (unless you prefer to remain anonymous).
